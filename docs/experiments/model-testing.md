# Choosing a provider for ASB tests

The installation smoke test asks one question through OpenClaw and checks the real model's answer and output-token count. Maintenance tests ask a different question: after a configuration change or upgrade, can this gateway still deliver a **new** request to the configured provider and return its response?

## Local-model trials

The CPU trials used llama.cpp and the prompt “What is the capital of France? Answer with just the name of the city.” Each attempt used a new OpenClaw session. A pass required an OK turn from `lab/asb-local`, at least one output token, and a reply containing “Paris”. The table covers the completed turns saved by the trial script. [Recorded turns](local-model-turns.jsonl)

| Trial label | Weights | Passing turns / recorded turns |
| --- | --- | --- |
| smol | SmolLM2-135M-Instruct Q4_K_M | 0 / 1 |
| gemma_builtin | Gemma 3 270M IT Q4_K_M | 0 / 1 |
| lfm | LFM2-350M Q4_K_M | 0 / 1 |
| q4 | Qwen2.5-0.5B-Instruct Q4_0 | 5 / 5 |
| qwen | Qwen2.5-0.5B-Instruct Q4_K_M | 10 / 10 |
| lfm25 | LFM2.5-350M Q4_K_M | 5 / 5 |

These observations apply to this prompt and configuration. The `wall` field in the recorded data measures elapsed time for the agent command. The default lab uses the 229 MB LFM2.5 weights. [Model selection PR](https://github.com/mamachanko/abs-trial/pull/1)

## Facade trial

A small loopback HTTP server stood in for llama.cpp in a clean Ubuntu lab. OpenClaw 2026.11.6 sent two independent streaming requests to `/v1/chat/completions`. Each included a unique ID in the user messages. In both cases the agent CLI returned the exact receipt generated by the server. OpenClaw added another user-role message after the original prompt, so the fixture searches all user messages for the ID.

The checked-in tests repeat this experiment during gateway maintenance and use a fresh ID for each turn. CI also runs the default install against real weights. [Provider fixture](../../tests/fixtures/model-facade.cjs) · [Integration tests](../../tests/test_openclaw.py)

```sh
uv run --locked pytest -v -s --log-cli-level=INFO -m 'not real_model' tests/test_openclaw.py
uv run --locked pytest -v -s --log-cli-level=INFO -m real_model
```
